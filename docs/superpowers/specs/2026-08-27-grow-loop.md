## 1. How-to — “Get the most out of varimo”

### What it is

An in-app guide, not a blog. One page, five sections, phone-readable.
Goal: the second Generate is smarter than the first. Retention, not SEO.

### When to build

**After** the Claude Lab UI is the one Jeff wants. Placement, type, and nav
will change. Writing the **content** now is fine; shipping a `/how-to` tab
into today's TopNav is wasted chrome.

Suggested slot in the new IA: **More / Help / “Get more”** — not a sixth
primary tab. Solo already has Studio, Gallery, Flows, Drive.

### Voice

Direct. Operator-to-operator. No “spoof the platform.” No detector talk.
Product is: one master → many originals that still look like the take.

### Page map

**Hero (one screen)**
- Title: Get the most out of varimo
- One line: One good take. Many originals. Post them like they were shot that way.
- Three chips: Fast 8 first · 1080 is enough · Paste the real caption

**1. Start with the right clip**
- Front-camera talking-head or a simple motion take. 1080×1920, 15–40s is the
  happy path.
- 4K iPhone is fine — Studio already proxies to 1080. You do not need 4K for
  uniqueness.
- A 60s clip × Fast 20 is a long sit. Duration × copies is the wait, not
  megabytes. If you want it back in a sitting, start at **8 copies**.
- Don't cancel mid-pack. Look stills arrive first; the mp4s copy back when
  the pack finishes.

**2. Generate like you mean to post**
- Paste the **original caption**. Each copy gets a real riff, not “Alt take N.”
- Fast is the daily driver. HQ is the later reconstructive pass — not the
  default.
- Uniqueness pass is ~38% vs the source (24 bits). 65–72% is a comfortable
  pass, not “almost.” Under 30% does not ship.
- One pack, then slice it: main / trial / growth accounts each get
  **different files**. Do not send the same 20 to three Repurpose queues.

**3. Get it off the phone the right way**
- iPhone: Save = share sheet, files only. Do not fight Safari downloads.
- Drive: share the folder with `studio@varimo.io` as Editor. Operators do
  **not** Connect their own Google.
- Name the Drive destinations after the account role (`Maya / main`), not
  after the caption.

**4. Post like they are originals**
- One file, one account. Stagger times. Don't dump a 20-pack onto one
  profile in ten minutes.
- Keep the caption that came with the copy. That's the post.
- If a platform flags one, mark it Flagged in Gallery / Drop Ledger. Don't
  re-upload the same file.

**5. When it feels slow or “off”**
- Long wait + 1080 + 20 copies + ~1 min source = expected. Not stuck.
- Washed-out / cheap look = a color bug; tell Jeff. Do not “fix” it by
  desaturating.
- Need another studio for a creator? Ask Jeff — Solo vs Agency is set on
  the invite, before they sign in.

### Empty / first-run beat

First Generate on a new workspace: a 3-line card on Studio
(“8 copies · paste the caption · 1080 is enough”) that links to the full
how-to. Not a modal wall.

## 2. Weekly usage — count this before you price it

We do **not** have Creator quotas on live (launch caps stay parked).
Turn metering on as **readout first**, hard gate later.

### What to count

A pack is not a pack. Today's 66s Fast 20 is an order of magnitude more
work than a 7s Fast 8.

**Primary unit:** `variant_seconds` = `source_duration_s × delivered_ok_copies`

Optional second line (ops only): Fast wall-clock minutes, HQ minutes.

Do **not** meter upload MB. Do **not** meter uniqueness %. Do **not**
raise `TARGET_BITS` to “make usage more valuable.”

### Window

Rolling **7×24h** per workspace (not per seat). Agency VAs share the
owner's pool. Reset Monday 00:00 UTC is fine if Jeff wants a story;
rolling is fairer for a mid-week signup.

### Soft vs hard

1. **Soft (now-shaped):** show “this week · ~N min of copies” on Studio.
   Never block Jeff. Never block a pack already running.
2. **Hard (with a paid plan):** refuse **new** Generate when the workspace
   is over. Copy: “This week's copies are used. Next window starts {date}.”
   Do not kill an in-flight job.

### Why this unblocks pricing

Once we see two weeks of real `variant_seconds` per workspace, the other
chat can pick plan sizes (e.g. “about four 30s Fast-8s” vs “about two
60s Fast-20s”) without guessing. Until then, any $ number is a vibe.

Admin already has running / Fast / HQ / last job. Reuse that, add a
7-day sum. No Stripe required for the readout.

## 3. Paywall + landing

Two products that share a brand, not one page with a Generate button.

```
Public landing  →  Sign up / Sign in  →  Checkout (later)  →  Studio
varimo.io           /login or modal        Stripe              app
```

**Today:** `www.varimo.io` **is** Studio + AuthGate. A TikFusion-style
homepage cannot live there without moving the app.

**Recommended split (when we build it):**
- `www.varimo.io` — public landing (no login cookie required)
- `app.varimo.io` (or `studio.varimo.io`) — current Studio
- `/login` stays password-only
- Google login stays **off** until verification (Drive Connect unchanged)

Invite-only can stay for the first landing: “Request access” / “I have a
login” rather than open signup. Public paid signup is Wave 6 — after
usage numbers exist.

### Landing sections (TikFusion energy, varimo voice)

1. **Hero** — full-bleed phone mock of three variants of one talking-head.
   Wordmark + tagline. Primary: Get access / Sign in. No Google button.
2. **The trick** — one take → many originals. 3-up before/after, not a
   feature grid.
3. **How it works** — Drop a clip → Fast copies → captions → Save or Drive.
   15 seconds of copy. Link “Get the most out of it” for the deep how-to
   (that page can live on the landing *and* in-app).
4. **Who it's for** — solo creator vs a small shop. Agency chrome (Drops,
   Team) mentioned once, not as the hero.
5. **Plans** — placeholder tiles until the pricing chat locks numbers.
   Show **what you get** in `variant_seconds` language (“about X minutes
   of 1080 copies / week”), not “unlimited AI.”
6. **Sign in** — email + password. Invite-only footnote.
7. **Footer** — lowercase varimo, no detector claims.

### Paywall (later)

- Stripe Checkout on the landing CTA.
- Webhook writes `plan` + `period_end` onto the workspace.
- Studio Generate checks the weekly meter + plan.
- Owner pays; VAs ride the workspace pool.
- Jeff / site admin: unlimited, no banner.

Do not build Stripe this week. The landing can ship with “Request access”
and a Sign-in that already exists.
