3A Desktop · six screens
The web app is not the phone app stretched.
Nine nav items and four status chips currently share one top bar, and every page is a single 700px column of stacked cards on a 1440px screen. Desktop gets: a persistent rail that separates the five working pages from Team / Admin / Diagnostics, a slim context bar, two-column pages so setup sits beside live state instead of above it, and a variant view that takes over only the grid pane — rail and pack list stay put, so you never lose your place. Teal palette kept; brand type (Sora + Space Grotesk) and the echo wordmark come from the brand folder, drawn in teal rather than violet.
